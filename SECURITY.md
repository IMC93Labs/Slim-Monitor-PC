# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Slim Monitor PC.

## Reporting a vulnerability

Please do **not** publish sensitive vulnerability details in a public issue. Use GitHub's private security reporting features for this repository when available, or contact the project maintainers through the IMC93Labs GitHub organization.

Slim Monitor PC does not capture network packets, inspect their contents, or require administrator privileges. It reads Windows network-interface byte counters only.
