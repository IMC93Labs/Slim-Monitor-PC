# Slim Monitor PC v0.2.8

Final Windows 11 integration refinement focused on making the unified traffic/time/date block look and behave like a native part of the taskbar.

## Visual integration

- Keeps the approved v0.2.7 width unchanged.
- Trims only a couple of extra pixels from the top edge so the block stays below the Windows 11 taskbar shadow/separator instead of protruding above it.
- Keeps the bottom edge covering the native Windows clock/date underneath.
- Rebalances the internal columns and rate font so the complete `B/s`, `KB/s`, `MB/s` and `GB/s` suffix remains visible without widening the block.
- Adds a rounded Windows 11-style hover highlight when the pointer is over the block, matching the interaction of the nearby tray controls.

## Show desktop stability

- Adds a native window-position guard that rejects transient hide/minimize requests generated by **Show desktop** while the taskbar is still meant to be visible.
- Adds a fast visibility/Z-order guard so an unexpected shell transition is repaired in tens of milliseconds rather than visibly disappearing and returning later.
- Tightens fullscreen detection so genuine fullscreen games/apps are still allowed to hide Slim Monitor PC, while desktop/Explorer transitions are never treated as fullscreen.

## Preserved

- Unified Wi-Fi traffic + time + date display.
- No hover tooltip.
- Right-click network/session information.
- Built-in calendar on left click.
- Start with Windows.
- Centered upload/download executable icon.
- Single-file, self-contained Windows x64 executable.
- Startup self-test and embedded-icon validation in CI.
